    Linked Workers

    Add headless encoding workers with the URL and one-time code shown in their Docker logs. The controller transfers each job automatically, so workers do not need your media drives.

    Node linking tutorial

    1. Start the worker

    1. Run docker compose -f docker-compose.worker.yml up -d.
    2. Run docker logs bytesqueeze-worker.
    3. Copy the large one-time pairing code from the log banner.

    2. Pair from the controller

    1. Enter the worker URL, such as http://192.168.1.50:8082.
    2. Paste the code and optionally give the worker a friendly name.
    3. Click Pair and verify. The controller immediately tests the secure session.

    3. One work drive

    The worker has one mount: /work. Pairing state and the current temporary encode live there.

    The controller streams the source to that drive, the worker encodes locally, and the finished -TSD file is uploaded and verified before temporary files are removed.

    4. Send jobs

    1. Use Library to select Local queue, Best worker, or a specific worker.
    2. The controller sends the selected preset JSON to the worker with each node job.
    3. Set each worker's GPU slots below. CPU/software work always remains limited to one.

    Open the complete Headless Worker Setup guide for Linux, Unraid, Windows, drive sizing, updates, and troubleshooting.
